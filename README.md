# Stock Predictor

A Streamlit web application for stock analysis and short-term forecasting using historical data, time series modeling, and AI-generated insights.

## Overview

This application allows users to search for stocks, visualize historical performance, and generate 30-day forecasts. It combines statistical modeling with natural language summaries to provide an interpretable view of potential price trends.

## Features

* Historical price visualization with 50-day and 200-day moving averages
* Key metrics including current price, annual return, and 52-week range
* 30-day forecasting using Prophet with confidence intervals
* AI-generated outlook summarizing trends and projections
* Support for single-stock analysis and side-by-side comparison

## Tech Stack

* Streamlit (frontend)
* yFinance (data source)
* Pandas, NumPy (data processing)
* Prophet (time series forecasting)
* Ollama / Groq API (LLM-based insights)
